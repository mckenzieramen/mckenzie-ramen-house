V44 PASSWORD RESET FIX

The Forgot Password UI now tries the branded Cloud Function first. If the branded service is not yet deployed/configured, it automatically falls back to Firebase's native password-reset sender so the customer still receives a working reset email instead of an error.

For the professional branded email (with a clickable "Reset My Password" button and no raw URL), deploy the functions folder and configure the RESEND_API_KEY and RESEND_FROM_EMAIL secrets. Then use PASSWORD_RESET_EMAIL_TEMPLATE.txt as the design reference.

If the fallback is used, Firebase sends its configured password-reset template. Configure that template in Firebase Console > Authentication > Templates > Password reset email.

Do not put API keys or secrets in index.html or GitHub.
